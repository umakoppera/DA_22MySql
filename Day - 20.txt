Relationships:
---------------
relationships are used for establishment for relationships

1)Uniary relationship - it maintains same relationship

2)Binary relationship - it relationship b/w two tables

3)Tinary relationship - relationship b/w three tables

4)N-relationship - the relationship b/w more than one table

Types of relationship association:
-----------------------------------
one-one : the first table row is relationship b/w second table any one row in single table
one-many: the first table any row relationship b/w more than one row in second table
many-one : the first table contains more than one row relationship b/w second table
many-many: multiple records in first table can relate to multiple records in second table
