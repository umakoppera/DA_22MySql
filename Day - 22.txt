Normalization:
-----------------
it is way to process & organizing the data into tables
in database 
main advantages of normalization:
----------------------------------
to reduce the data redundancy
to avoid the duplicate values into a column
to maintain data consistency
easy to write insert,update,delete queries

normalization is work through using normal forms
1NF
2NF
3NF

1NF:
-----------
1NF stands for first normal form
in table satisfy inf,when every column contains atomic
value(single values)

2NF:
----------
second normal form
the table is satisfied in 2nf,when the table satisfy
1nf and remove the partialdependency
1nf+no partialdependency

3NF:
-------------
third normal form
2nf+no transtivedependency

composite key:
---------------
in one table combine the more than one column identify
uniquely.
