Subquery:
-------------
to write a query inside another query
the subquery enclosed with in paranthesis.

select query condition(subquery);

singlerow subquery:
---------------------
the subquery returns only one row that is called single row subquery
using >,<,=,>=,<= etc

multirow subquery:
---------------------
the subquery returns more than one row that is called multirow subquery
using any,all,some,In

nested subquery:
-----------------
multilevel of subquery is called as nested subquery.
